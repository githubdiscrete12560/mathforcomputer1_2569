สไลด์ 3 NumPy · Row Vector
อาเรย์ 1 มิติ และการดำเนินการ
# แต่ละแถว = row vector (shape 3,2) import numpy as np data = np.array([[2, 5], [1, 3], [4, 2]]) row0 = data[0] # [2 5] row1 = data[1] # [1 3] row2 = data[2] # [4 2]

การใช้งานทั่วไป

  • ระยะทาง: np.linalg.norm(row0 - row1)
  • ดอทโปรดักท์: np.dot(row0, row1) → 17
  • ขนาด (norm) แต่ละตัว: np.linalg.norm(data, axis=1)

ข้อดี

  • เร็ว · รองรับเวกเตอร์ไลเซชัน
  • ใช้ในโมเดล ML, การแปลงเชิงเส้น
  • ทำงานร่วมกับ SciPy, scikit-learn
scaled = data * 2 # scale dot = np.dot(data[0], data[1]) # 17
สไลด์ 4 Pandas · Row Vector
Series และการเข้าถึงด้วยป้ายชื่อ
import pandas as pd df = pd.DataFrame({ 'weight': [2, 1, 4], 'height': [5, 3, 2] }, index=[0, 1, 2]) row0 = df.loc[0] # Series: weight=2, height=5 row1 = df.loc[1] # Series: weight=1, height=3 row2 = df.loc[2] # Series: weight=4, height=2

การใช้งานที่พบบ่อย

  • กรองข้อมูล: df[df['height'] > 3]
  • เพิ่มคอลัมน์: df['bmi'] = ...
  • แปลงเป็น NumPy: df[['weight','height']].values
เข้าถึงด้วย index (0,1,2) หรือ label
