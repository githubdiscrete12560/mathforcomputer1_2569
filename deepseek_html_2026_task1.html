Linear Transformations in Python

NumPy linearity ℝ²

From basis vectors to matrix multiplication — step by step

e₁ = [1, 0]ᵀ  ·  e₂ = [0, 1]ᵀ
v = 3e₁ + 2e₂
A = [[2, 1], [0, 1]]

→ We’ll transform basis vectors, then use linearity to transform v.

Python NumPy linear algebra

🧱 The building blocks

We start with standard basis vectors, a vector v, and a matrix A.

import numpy as np

# Standard basis vectors of R²
e1 = np.array([[1], [0]])
e2 = np.array([[0], [1]])

# v = 3·e1 + 2·e2
v = 3 * e1 + 2 * e2

# transformation matrix
A = np.array([[2, 1], [0, 1]])
e₁ = [[1] [0]]
e₂ = [[0] [1]]
v = [[3] [2]]
A = [[2 1]
[0 1]]

v = 3·e₁ + 2·e₂ → coordinates (3, 2) in the standard basis.

📐 The R² plane

e₁ = (1, 0)
e₂ = (0, 1)
v = (3, 2)
v = 3·e₁ + 2·e₂
Visual idea
  • 🔴 e₁ → horizontal
  • 🔵 e₂ → vertical
  • 🟢 v = 3 right + 2 up

The matrix A will move these arrows.

🔁 1. Transform the basis vectors

A @ e₁ and A @ e₂ give the columns of A.

Ae1 = A @ e1
Ae2 = A @ e2

# outputs:
Ae1 = [[2] [0]]    Ae2 = [[1] [1]]
A e₁ = [2, 0]ᵀ    A e₂ = [1, 1]ᵀ
✅ These are exactly the columns of A.

⚡ 2. Transform v directly

Multiply matrix A by vector v.

A v = [[2, 1], [0, 1]] · [3, 2]ᵀ = [8, 2]ᵀ
Av_direct = A @ v    # [[8] [2]]
Output: [[8] [2]]

🧩 3. Use linearity

Since v = 3e₁ + 2e₂, and transformations are linear:

A v = A(3e₁ + 2e₂) = 3·Ae₁ + 2·Ae₂
Av_from_basis = 3 * Ae1 + 2 * Ae2
# output: [[8] [2]]
3·Ae₁ = 3·[2,0] = [6,0]
2·Ae₂ = 2·[1,1] = [2,2]
sum = [6,0] + [2,2] = [8,2] ✅

🎯 The core idea

Columns of A = images of basis vectors
A e₁ = first column
A e₂ = second column
Therefore:
A · [3, 2]ᵀ = 3·(first col) + 2·(second col)

📄 Complete Python implementation

import numpy as np

# 1. basis vectors
e1 = np.array([[1], [0]])
e2 = np.array([[0], [1]])

# 2. v = 3e1 + 2e2
v = 3 * e1 + 2 * e2

# 3. matrix A
A = np.array([[2, 1], [0, 1]])

# 4. transform basis
Ae1 = A @ e1
Ae2 = A @ e2

# 5. direct
Av_direct = A @ v

# 6. using linearity
Av_from_basis = 3 * Ae1 + 2 * Ae2

# 7. results
print("Ae1 =", Ae1)
print("Ae2 =", Ae2)
print("Av_direct =", Av_direct)
print("Av_from_basis =", Av_from_basis)
print("Equal?", np.array_equal(Av_direct, Av_from_basis))
✅ Output: both methods give [[8] [2]]  ·  True

🧠 The two results are identical — linearity holds.
